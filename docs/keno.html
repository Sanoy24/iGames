Keno Game Engine

Pick 1–12 numbers from 1–80. 20 numbers are drawn. Match more to win more.

How Keno Works

  1. Player picks numbers — selects 1 to 12 unique numbers from the range 1–80 (the "spot count").
  2. Ticket is purchased — wallet is debited the ticket price in the same transaction as ticket creation.
  3. Draw executes — the RNG service draws 20 unique numbers from 1–80.
  4. Matches are counted — the system compares the player's selected numbers against the 20 drawn numbers.
  5. Payout is calculated — based on the spot count and match count, a multiplier from the paytable is applied to the stake.
  6. Settlement — winning tickets are credited to the player's wallet; losing tickets are marked as lost.

Winning Logic (KenoRulesService)

1. Match Counting

countMatches(selectedNumbers, drawnNumbers):
  drawn = Set(drawnNumbers)
  return selectedNumbers.filter(n => drawn.has(n)).length

Creates a Set from the 20 drawn numbers, then counts how many of the player's selected numbers appear in that set.

2. Payout Calculation

calculatePayoutMinor({ stakeMinor, spotCount, matches, config }):
  entry = config.paytable.find(e => e.spots === spotCount && e.matches === matches)
  if (!entry) return 0
  return stakeMinor * entry.payoutMultiplier

Looks up the paytable for the exact combination of (spots, matches). If found, multiplies the player's stake by the multiplier. No match in the paytable = no payout.

3. Ticket Status

ticket.status = payoutMinor > 0 ? 'won' : 'lost'

Only one config can be active at a time. Creating a new config deactivates the previous one in a transaction. Configs are versioned (version field with a unique index).

Settlement Flow (in detail)

Inside settleDrawTickets(), for each pending ticket:

  1. Count matches between ticket.selectedNumbers and draw.drawnNumbers.
  2. Calculate payout via the paytable lookup.
  3. Set ticket.status to 'won' or 'lost'.
  4. If won: call walletService.creditInSession() with idempotency key keno-settlement:{ticketId}.
  5. Save the ticket and accumulate settlement summary stats.

The entire settlement happens inside a single MongoDB transaction — if any credit fails, everything rolls back.

Ticket Purchase Idempotency

Each ticket purchase requires an idempotencyKey. Before creating a new ticket, the service checks:

existingTicket = findOne({ userId, idempotencyKey })
if (existingTicket) return existingTicket  // No duplicate charge

The wallet debit uses key keno-ticket:{idempotencyKey} for its own idempotency layer.

Draw Cancellation

If a draw is cancelled before settlement, all pending tickets are refunded:

  • Each ticket gets status: 'cancelled', payoutMinor: 0.
  • The original stake is credited back via walletService.creditInSession() with entryType: 'refund'.
  • Idempotency key: keno-refund:{ticketId}.
