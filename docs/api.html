API Reference

All REST endpoints exposed by the iGames backend. Full interactive docs available at /docs (Swagger UI).

📡
The live Swagger/OpenAPI documentation is auto-generated at http://localhost:3000/docs when the server is running.

Error Response Format

All errors follow a structured format via the HttpExceptionFilter:

{
  "statusCode": 400,
  "message": "Selected spot count is not allowed",
  "error": "Bad Request",
  "requestId": "req-abc123-def456"
}

The requestId is injected by the request ID middleware and can be used for log correlation.

Authentication Header

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

All Bearer endpoints require a valid JWT access token. Admin endpoints additionally require the admin role in the token's roles[] claim.
