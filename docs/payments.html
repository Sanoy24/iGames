Telebirr Payments

Manual receipt-based wallet top-up flow using Ethiopia's Telebirr mobile payment system.

How It Works

This is a manual top-up flow — the user pays outside the app via Telebirr, then submits the receipt to get credits:

User pays via Telebirr
→
Submits receipt number
→
Backend fetches receipt page
→
Parses & verifies
→
Checks for reuse
→
Credits wallet

Verification Steps

The TelebirrReceiptVerifierService performs multi-layer verification:

  1. Receipt extraction — accepts either a receipt number (ADQ123...) or a full URL (https://transactioninfo.ethiotelecom.et/...). URLs are validated to ensure the hostname is transactioninfo.ethiotelecom.et.
  2. Receipt number validation — must match /^[A-Za-z0-9_-]{4,80}$/.
  3. Fetch receipt HTML — uses the telebirr-receipt npm package to load the official receipt page.
  4. Parse receipt — extracts fields: receiptNo, settled_amount/total_amount, transaction_status, credited_party_name, credited_party_acc_no.
  5. Transaction status check — must contain one of: completed, success, successful, paid (case-insensitive).
  6. Receiver name match — if TELEBIRR_EXPECTED_RECEIVER_NAME is configured, the receipt's credited party name must match (normalized, case-insensitive).
  7. Receiver account match — if TELEBIRR_EXPECTED_RECEIVER_ACCOUNT is configured, the receipt's account number must match.
  8. Amount conversion — Birr amount is converted to minor units using TELEBIRR_CREDIT_MINOR_PER_BIRR multiplier.

Receipt Reuse Prevention

The PaymentsService stores submitted receipts in a TelebirrReceipt collection with a unique index on receiptNo. If a receipt number has already been used, the submission is rejected with a conflict error.

Environment Configuration

Env VariableRequiredDescription
TELEBIRR_EXPECTED_RECEIVER_NAMEOptionalExpected recipient name on the receipt. If set, receipts to other recipients are rejected.
TELEBIRR_EXPECTED_RECEIVER_ACCOUNTOptionalExpected recipient account number. Same behavior as above.
TELEBIRR_CREDIT_MINOR_PER_BIRRYesConversion rate. E.g., 1 means 1 Birr = 1 credit minor unit.

API Endpoint

POST /payments/telebirr/receipts
Authorization: Bearer <access-token>
Content-Type: application/json

{
  "receiptNo": "ADQ123456789"
  // OR
  "receiptNo": "https://transactioninfo.ethiotelecom.et/receipt/ADQ123456789"
}

On success, the wallet is credited and the response includes the ledger entry details.

⚠️
Failure modes: If the Telebirr receipt page is unreachable, the service throws ServiceUnavailableException. If the receipt is invalid or has been used before, BadRequestException or ConflictException is returned.
